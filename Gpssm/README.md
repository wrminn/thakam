# Garbage Payment System (ระบบจัดการขยะและการชำระเงิน)

ระบบต้นแบบสำหรับจัดการคำร้องขอถังขยะ การชำระค่าบริการ และการแจ้งเหตุฉุกเฉินของเทศบาล พัฒนาด้วยเทคโนโลยีสมัยใหม่เพื่ออำนวยความสะดวกให้กับประชาชนและเจ้าหน้าที่เทศบาล

## 🎯 ภาพรวมโปรเจค

**Garbage Payment System** เป็นระบบเว็บแอปพลิเคชันที่พัฒนาขึ้นเพื่อช่วยเหลือเทศบาลในการจัดการด้านสิ่งแวดล้อมและสาธารณสุข โดยเฉพาะอย่างยิ่งการจัดการขยะมูลฝอยและการให้บริการที่เกี่ยวข้องกับประชาชน

### จุดเด่นของระบบ
- **คำร้องขอถังขยะ**: ประชาชนสามารถยื่นคำร้องขอถังขยะได้แบบออนไลน์ พร้อมอัปโหลดเอกสารแนบ
- **ระบบชำระเงิน**: ชำระค่าบริการเก็บขยะผ่านระบบออนไลน์อย่างปลอดภัยด้วย Stripe
- **แจ้งเหตุฉุกเฉิน**: รายงานเหตุฉุกเฉินที่เกี่ยวข้องกับขยะหรือสิ่งแวดล้อม
- **ติดตามสถานะ**: ติดตามสถานะรถเก็บขยะและจุดทิ้งขยะอันตราย
- **ธนาคารขยะ**: ข้อมูลหน่วยรับซื้อขยะรีไซเคิล
- **แดชบอร์ดผู้ใช้**: จัดการข้อมูลส่วนตัวและประวัติการใช้งาน

## 🚀 ฟีเจอร์หลัก

### สำหรับประชาชนทั่วไป
1. **คำร้องขอถังขยะ**
   - กรอกข้อมูลส่วนตัวและที่อยู่
   - เลือกประเภทสถานที่ (บ้าน/ร้านค้า/โรงงาน)
   - อัปโหลดเอกสารแนบ (รูปภาพ, PDF)
   - ระบุพิกัดบนแผนที่
   - ยื่นคำร้องแบบไม่ต้องล็อกอินหรือล็อกอินเพื่อติดตามสถานะ

2. **การชำระเงิน**
   - ชำระค่าบริการเก็บขยะรายเดือน
   - ดูประวัติการชำระเงิน
   - รับใบเสร็จอิเล็กทรอนิกส์

3. **แจ้งเหตุฉุกเฉิน**
   - รายงานเหตุขยะล้น, ถังขยะชำรุด
   - รายงานจุดทิ้งขยะผิดกฎหมาย
   - แจ้งเหตุเพลิงไหม้หรืออุบัติเหตุที่เกี่ยวข้อง

4. **ข้อมูลบริการ**
   - ค้นหาจุดให้บริการต่าง ๆ
   - ข้อมูลธนาคารขยะและจุดรับซื้อของรีไซเคิล
   - ติดตามสถานะรถเก็บขยะแบบเรียลไทม์

### สำหรับเจ้าหน้าที่เทศบาล
- **แดชบอร์ดการจัดการ**
  - จัดการคำร้องขอถังขยะ
  - ติดตามการชำระเงิน
  - จัดการเหตุฉุกเฉิน
  - สถิติและรายงานต่าง ๆ

## 🛠️ เทคโนโลยีที่ใช้

### ฝั่งไคลเอนต์ (Frontend)
- **React 18** - ไลบรารีสำหรับสร้าง UI
- **TypeScript** - เพิ่มความปลอดภัยให้กับโค้ด
- **Vite** - เครื่องมือสร้างและพัฒนาเว็บแอปที่รวดเร็ว
- **Tailwind CSS** - กรอบงาน CSS สำหรับการออกแบบที่ยืดหยุ่น
- **Radix UI** - คอมโพเนนต์ UI ที่เข้าถึงได้และปรับแต่งได้
- **React Query** - จัดการข้อมูลและการโหลดแบบ asynchronous
- **React Router** - จัดการเส้นทาง (routing)
- **Leaflet** - แสดงแผนที่และพิกัด
- **Stripe** - ระบบการชำระเงินที่ปลอดภัย

### ฝั่งเซิร์ฟเวอร์ (Backend)
- **Laravel 11** - PHP web framework ที่ทรงพลัง
- **PostgreSQL** - ฐานข้อมูลเชิงสัมพันธ์ที่มีประสิทธิภาพสูง
- **JWT Authentication** - การยืนยันตัวตนที่ปลอดภัย

### การพัฒนาและเครื่องมืออื่น ๆ
- **ESLint** - ตรวจสอบคุณภาพโค้ด
- **Prettier** - จัดรูปแบบโค้ดให้เป็นมาตรฐาน
- **Vitest** - ทดสอบหน่วยสำหรับโค้ด

## 📊 โครงสร้างฐานข้อมูล

ระบบใช้ฐานข้อมูล PostgreSQL ที่ประกอบด้วยตารางหลักดังนี้:

### `users` - ผู้ใช้ระบบ
- `id`, `email`, `password_hash`, `full_name`
- `created_at`

### `bin_requests` - คำร้องขอถังขยะ
- `id`, `user_id` (เชื่อมกับผู้ใช้)
- ข้อมูลผู้ยื่นคำร้อง: `prefix`, `full_name`, `age`, `phone`, `email`
- ที่อยู่: `house_no`, `moo`, `road`, `subdistrict`, `district`, `province`, `postcode`
- รายละเอียด: `place_type`, `place_type_other`, `lat`, `lng`, `detail`
- ไฟล์แนบ: `attachments` (JSON array)
- `consent`, `created_at`

### `payments` - การชำระเงิน
- `id`, `user_id` (เชื่อมกับผู้ใช้)
- `bill_code`, `address`, `amount`, `status`
- `paid_at`, `due_month`, `due_year`, `created_at`

### `emergencies` - เหตุฉุกเฉิน
- `id`, `title`, `reporter_name`, `phone`, `description`
- `category`, `lat`, `lng`, `photo_url`, `created_at`

## ⚡ การติดตั้งและรัน

### ข้อกำหนดเบื้องต้น
- **PHP 8.2+** และ **Composer**
- **Node.js 18+** และ **npm**
- **PostgreSQL** (ฐานข้อมูล)
- **Git** (สำหรับ clone โปรเจค)

### ขั้นตอนการติดตั้ง

1. **โคลนโปรเจค**
   ```bash
   git clone <repository-url>
   cd Garbage Payment System
   ```

2. **ติดตั้ง dependencies ของเซิร์ฟเวอร์**
   ```bash
   cd server-laravel
   cp .env.example .env
   # แก้ไข .env ให้เชื่อมต่อฐานข้อมูล
   composer install
   php artisan key:generate
   php artisan migrate
   php artisan storage:link
   ```

3. **ติดตั้ง dependencies ของไคลเอนต์**
   ```bash
   # จากโฟลเดอร์รากของโปรเจค
   npm install
   ```

4. **รันเซิร์ฟเวอร์**
   ```bash
   # Terminal 1: รัน Laravel API
   cd server-laravel
   php artisan serve

   # Terminal 2: รัน React App
   npm run dev
   ```

5. **เปิดเว็บเบราว์เซอร์**
   - Laravel API: `http://localhost:8000`
   - React App: `http://localhost:5173`

## 📝 หมายเหตุสำหรับนักพัฒนา

- โปรเจคนี้ถูกย้ายจาก Node.js (Express + Drizzle) มาเป็น Laravel เพื่อให้เหมาะกับทีมที่ถนัด PHP
